### Version-bump decision

The roadmap's `v1.0`/`v1.5` are **product milestones** layered on the
`v0.1-alpha` scaffold; consistent with the v1.0 completion (which left every
`package.json` at `0.1.0-alpha.0`), the npm package versions are **not**
bumped here. The milestone status is represented in the README, which now
records v1.5 as complete. `apps/cli/src/cli.test.ts` asserts the CLI version
string `0.1.0-alpha.0`; `bundle.test.ts` deliberately asserts commander
*capability*, not a version string, so no version-dependent test needed
changing.

### Scope honored

Draft-only, as chosen: no SMTP client, no stored mail credentials, no
automatic sending, no open/click/bounce tracking. "Mark as sent" is the
human-in-the-loop confirmation that logs a real `email_sent` interaction
(feeding Phase 7 relationship scoring) and advances the drip; a recorded reply
logs an inbound `email_received` and cancels the remaining steps. Deferred and
documented in the design spec: SMTP delivery, background send workers,
open/bounce/unsubscribe tracking, AI-composed campaign templates, and A/B
testing.
